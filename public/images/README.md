Export image assets from Figma into this folder.

Recommended file names used by the scaffold:
- news-1.png
- news-2.png
- news-3.png
- saved-1.png
- saved-2.png

How to export from Figma:
1. Select a frame/layer in Figma.
2. In the right panel, use Export.
3. Use PNG for UI elements and JPG for photos.
4. Export at 1x and 2x if needed.
5. Rename files to match the list above and place them here.

These files are referenced as /images/<file-name> in mock article data.
